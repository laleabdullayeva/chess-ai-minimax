# Chess AI — Minimax & Alpha-Beta Pruning

A Python-based chess game where a human player competes against an AI opponent.

## About the Project

This project demonstrates the application of intelligent search algorithms in chess. The AI evaluates possible moves and selects a suitable move using the Minimax algorithm and Alpha-Beta Pruning.

## Features

- Play chess against an AI opponent
- Graphical interface built with Pygame
- Move selection and legal move validation
- Minimax search algorithm
- Alpha-Beta Pruning optimization
- Board evaluation based on piece values
- AI search statistics

## Technologies

- Python
- Pygame
- python-chess

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Game

```bash
python chess_gui.py
```

## Algorithms

**Minimax:** Explores possible moves and the opponent's responses to evaluate the game state.

**Alpha-Beta Pruning:** Reduces unnecessary search by skipping branches that cannot affect the final decision.

## Project Purpose

The purpose of this project is to understand and demonstrate how intelligent search algorithms can be applied to a two-player strategy game.
